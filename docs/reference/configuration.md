# Configuration

The export can be set up by a TOML file of its own ([guide](../guides/export.md#define-the-dataset-in-a-config-file),
[keys](#export-config)). A training run is set up by one TOML file, e.g. a copy of
[`examples/quick_start/train.toml`](https://github.com/stofe94/crash-def-net/blob/main/examples/quick_start/train.toml):

```bash
python train/train.py --config configs/my_run.toml [--epochs N] [--device cuda]
```

- Every key has a default; a config sets only what differs. The defaults follow the
  papers where they give a value.
- Command line options of `train.py` override the TOML when they are given
  ([command line](cli.md#train)).
- Unknown keys are reported at start-up, so typos do not go unnoticed.
- The checkpoint stores the resolved config with only the settings in effect (no MGN-T
  settings for a MeshGraphNets run, and so on), with the source file, its SHA-256 and
  the overrides.

What the settings do during a run: [training](../concepts/training.md); the comparison
protocol fixes most of them ([protocol](../guides/comparison-protocol.md#training)).

## [data]

| Key | Default | Description |
|---|---|---|
| `data_dir` | `"data/deforming_plate_s10_small"` | Dataset folder written by the exporter (`dataset.db`, `normalizer.json`, `metadata.json`) |
| `num_dataloader_workers` | `0` | DataLoader processes that build the graphs; 0: in the main process (CPU), 2–4 on a GPU machine |
| `lazy` | `false` | Read the frames from `dataset.db` on access instead of loading the splits into memory, for splits that do not fit into RAM |
| `cache_frames` | `0` | Lazy: frames kept per process, least recently used out; 0: no cache |
| `static_cache_mb` | `1024` | Lazy: static graph data (mesh edges, world edge selection, rest positions) kept per process, in MB |
| `local_features` | unset | Local input features the model sees: static node features of the export by name (`static_feature_names` in `metadata.json`); `[]`: none; unset: all |
| `global_features` | unset | Global input features the model sees: run parameters of the export by name (`global_feature_names` in `metadata.json`); `[]`: none; unset: all |
| `target_fields` | unset | Result fields the model predicts besides the velocity, by name (`target_feature_names` in `metadata.json`), with their `<name>_prev` inputs; `[]`: the velocity only; unset: all |
| `start_frame` | unset | Raw frame of the run the training starts with: the first current frame of the samples and the initial state of the rollouts (validation, test, and by default `predict/rollout.py`), one of the dataset; unset: its first frame |
| `end_frame` | unset | Raw frame of the run the training ends with: the last target of the samples and of the rollouts, one of the dataset; unset: its last frame |

| Key | Default | Description |
